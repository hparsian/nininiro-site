# نی نی نی رو — نسخه‌ی اول سایت (استاتیک، آماده‌ی Cloudflare Pages)

## ساختار پروژه
```
/
├── index.html            صفحه اصلی
├── category.html         صفحه دسته‌بندی (نمونه: بادی نوزاد) + فیلترها
├── product.html          صفحه محصول + آکاردئون سوالات متداول + افزودن به سبد خرید
├── checkout.html         فرم تسویه‌حساب، سفارش را می‌سازد و به درگاه پرداخت هدایت می‌کند
├── checkout-success.html صفحه‌ی بازگشتِ بعد از پرداخت موفق (خودِ API ریدایرکت می‌کند)
├── checkout-failed.html  صفحه‌ی بازگشتِ بعد از پرداخت ناموفق/لغوشده
├── robots.txt / sitemap.xml
├── assets/
│   ├── css/style.css     تمام استایل‌ها و توکن‌های طراحی (رنگ، فونت) + استایل سبد خرید
│   ├── js/main.js        رفتارهای تعاملی (منو موبایل، آکاردئون، انتخاب سایز/رنگ)
│   ├── js/cart.js        اتصال به بک‌اند nininiro-api (سبد خرید، چک‌اوت) — ⚠️ آدرس API را اینجا تنظیم کن
│   └── img/
│       ├── logo-icon.webp        لوگوی هدر/فوتر (۹۲×۹۲، ~2KB)
│       ├── logo-hero.webp        تصویر Hero صفحه اصلی (۱۰۴۰×۱۰۴۰، ~53KB)
│       ├── og-image.webp         تصویر پیش‌نمایش شبکه‌های اجتماعی (۶۳۰×۶۳۰)
│       ├── favicon-32.png / favicon-64.png
│       └── apple-touch-icon.png  آیکون افزودن به صفحه اصلی iOS
└── README.md
```

سبد خرید و پرداخت به یک بک‌اند مستقل PHP به اسم **nininiro-api** وصل است (ریپوی جدا، چون سایت اصلی باید کاملاً استاتیک/Cloudflare Pages بماند). قبل از دیپلوی، آدرس واقعی آن API را در بالای `assets/js/cart.js` (متغیر `NNR_API_BASE`) جایگزین کن.

هیچ مرحله build ای لازم نیست؛ این یک سایت کاملاً استاتیک HTML/CSS/JS است.

## آپلود در Cloudflare Pages — روش سریع (Drag & Drop)
1. وارد داشبورد Cloudflare شوید → بخش **Workers & Pages**
2. روی **Create application → Pages → Upload assets** بزنید
3. کل پوشه‌ی این پروژه (یا فایل zip آن) را درگ‌اند‌دراپ کنید
4. نام پروژه را وارد کنید (مثلاً `nininiro`) و **Deploy** بزنید
5. آدرس موقت شما چیزی شبیه `nininiro.pages.dev` خواهد بود

## آپلود از طریق Git (روش پیشنهادی برای آینده)
1. این پوشه را در یک ریپازیتوری گیت‌هاب/گیت‌لب push کنید
2. در Cloudflare Pages گزینه‌ی **Connect to Git** را بزنید و ریپو را انتخاب کنید
3. Build command را خالی بگذارید، Output directory را `/` بگذارید
4. هر push به شاخه‌ی اصلی به‌صورت خودکار دیپلوی می‌شود

## اولویت‌بندی مراحل بعدی (پیشنهاد تیم)
1. **جایگزینی تصاویر placeholder** با عکس واقعی محصولات (باکس‌های "تصویر محصول")
2. **اتصال دامنه‌ی اختصاصی** به پروژه‌ی Cloudflare Pages
3. **دیپلوی nininiro-api و انتخاب درگاه پرداخت نهایی** — کد سبد خرید/چک‌اوت آماده است، فقط باید API هاست شود و `PAYMENT_GATEWAY` در `.env` آن تنظیم شود
4. تکمیل صفحات باقی‌مانده (لباس دخترانه، پسرانه، سیسمونی) با همین قالب `category.html`
5. اتصال فرم خبرنامه به یک سرویس واقعی (میلرلایت، وردپرس و ...)
6. افزودن صفحات «درباره ما»، «تماس با ما» و اولین ۳ مقاله‌ی وبلاگ از لیست ۵۰ عنوانه

## بهبودهای ظاهری/سرعت/سئو (آخرین به‌روزرسانی)
- **فونت‌ها واقعاً لود می‌شوند** — قبلاً Vazirmatn/Poppins فقط در CSS تعریف شده بودند ولی هیچ‌جا import نمی‌شدند؛ الان با `<link>` به Google Fonts + `preconnect` اضافه شده
- **لوگوی ۲۴۸ کیلوبایتی جایگزین شد** با چند نسخه‌ی بهینه‌شده به‌اندازه‌ی واقعی مصرف (آیکون هدر ~۲KB، تصویر Hero ~۵۳KB، favicon های PNG کوچک، تصویر og برای پیش‌نمایش شبکه‌های اجتماعی)
- تمام `<img>` ها حالا `width`/`height` دارند تا از پرش صفحه هنگام لود (CLS) جلوگیری شود
- `category.html` حالا `h1` دارد (قبلاً فقط `h2` بود — برای سئو هر صفحه باید دقیقاً یک h1 داشته باشد)
- کنتراست رنگ‌های `--ink-soft` و `--gold-deep` کمی تیره‌تر شد تا استاندارد WCAG AA (۴.۵:۱) را برای متن پاس کنند
- `preconnect` به دامنه‌ی API اضافه شد تا اولین درخواست `fetch` سبد خرید/جستجو کندتر از حد لازم نباشد
- دکمه‌ی منوی موبایل و آکاردئون سوالات متداول حالا `aria-expanded` دارند (قبلاً screen readerها نمی‌فهمیدند باز/بسته‌ست)
- فایل `_headers` برای Cloudflare Pages اضافه شد: کش یک‌ساله برای فایل‌های `assets/` (چون هش نمی‌شوند، بعد از هر تغییر خودِ فایل را دستی جایگزین کن تا کش قدیمی سرو نشود)، و هدرهای امنیتی پایه (`X-Frame-Options`, `Referrer-Policy`, ...)
  - ⚠️ یادداشت: چون سایت از `style="..."` و `<script>` داخل HTML استفاده می‌کند، یک CSP کامل و سخت‌گیرانه فعلاً اضافه نشده (نیاز به جدا کردن استایل/اسکریپت‌های inline دارد) — اگر لازم شد جداگانه انجامش می‌دهیم

## نکات طراحی
- پالت رنگ و لوگو مستقیماً از تصویری که آپلود کردید گرفته شده: طلایی گرم، کرم، صورتی ملایم و آبی آسمانی
- تمام صفحات راست‌به‌چپ (RTL) و ریسپانسیو تا موبایل هستند
- فونت فارسی: Vazirmatn (از Google Fonts بارگذاری می‌شود)
